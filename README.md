# CuyDorado

Página web para validar códigos del Boleto Dorado y registrar premios.

## Uso

Ingresa el código de tu boleto en la página para verificar si ganaste.

Si el código resulta ganador, podrás completar tus datos para solicitar el premio.

## Página web

[Visitar Cuy Dorado](https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/)

## Archivos principales

- `index.html`: página principal.
- `style.css`: estilos de la página.
- `ChatGPT.png`: imagen de fondo.

## Publicación

La página está publicada mediante GitHub Pages.
